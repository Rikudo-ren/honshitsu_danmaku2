# 弾幕パターン設計表（21 種）

`src/game/patterns.js` に実装されている全 21 パターンの設計表。
**下の数値はすべて NORMAL（各係数 = 1.0）のときの実値**で、ソースから抽出したもの。
EASY / HARD では `dif.n / v / iv / turn / safe / dense` を通して増減する
（例: HARD は同時数 ×1.42、間隔 ×0.78、弾速 ×1.18、ただし上限 372 px/s）。

## パターンの書き方（実装の約束）

```js
defPattern(key, { name, jp, novel, tags, make(dif) })
  → { update(dt, ctx) }
     ctx = { sys, dif, player, W, H, t, bx, by, ramp, rand(), aim(), sfx() }
```

- `new Tick(iv)` — 発射間隔。`dif.iv()` を通すので難易度で自動的に変わる。
- レーザーは `interval ≥ warnDur + fireDur + gap` を守る（無予告の発射を禁止）。
- 画面外から出す弾は自前で座標を置かず `spawnFromEdge()` を通す（予告マーカーが出る）。
- 弾速は `dif.v()` を通す。生成後に `speedCap` でクランプされ、
  検証（`tools/playthrough.js`）が上限違反を NG として報告する。

## 各パターンの設計

### 円形拡散系

**`ringsNavy` 区分けの輪** — `Tick(dif.iv(1.15))` / `dif.n(14 + ring%3)` 方向 / `dif.v(78 + (ring%4)*6)` px/s
発射位置はボス中心。リング状に**必ず等間隔の隙間**ができる。3 リングごとに同時数が増える。
弾種 `riceCream`。回避経路は「輪と輪の間を横に抜ける」。
役割は導入と**フェーズの土台**（他のレイヤがこの上に乗る）。原作の「区分け」＝
南棟と北棟を分ける見えない線を、均等に開く輪として描いている。

**`safeCenterCaldera` 火口** — `Tick(dif.iv(1.3))` / `dif.n(26)` 方向 / `dif.v(56)` px/s（外へ）
＋ `dif.n(4)` / `dif.v(52)`（内へ）。中心が**構造的な安全地帯**で、火の粉は外へ流れるだけ。
「美しいが中央が安全」という要求を満たす代表。原作では溶岩台地の比喩。

**`crossFlower` ✝の花** — `Tick(dif.iv(0.9))` / 腕 `dif.n(4)`〜`dif.n(5)` / `dif.v(64 + i*4)` px/s
弾種 `crossHonshitsu`（十字の弾）。十字の腕が回転しながら開く。
本作の記号そのものなので、全 4 章に渡って繰り返し現れる。

### 螺旋・掃引系

**`spiralEnji` 二重螺旋** — `Tick(dif.iv(0.085))` / 1 回 2 発 / `dif.v(70)` と `dif.v(96)`
紺（内進）とえんじ（理数科）が**逆向きに巻く**。発射間隔が非常に短いので、
画面には 2 本の曲線が残る。回避経路は「螺旋の外側を回る」。
高密度だが弾道が読めるため、HARD でも事故になりにくい。

**`sweepLaser` 掃引** — `Tick(dif.iv(2.8))` / `dif.n(10)` / `dif.v(76)` px/s ＋ レーザー
横切る光と、上下からの弾の複合。レーザーには必ず予告線が入る。
原作の「球技大会」＝時間に押される感覚。

### レーザー系

**`laserBoundary` 構造線** — `Tick(dif.iv(WARN + FIRE + GAP))`、回転するレーザー 3 本
＋ `dif.n(2)`〜`dif.n(6)` 方向 / `dif.v(58)` px/s の弾種 `riceCyan`。
**「レーザーの無い時間」が必ず訪れる**ように周期を設計している。
糸魚川-静岡構造線＝日本の地質を分ける線をそのまま回転光にした。

### 壁・開閉系

**`wallMiso` 味噌の境界** — `Tick(dif.iv(1.5))` / `dif.n(11)` 列 / `dif.v(92)` px/s
上下から迫る壁に、**必ず一つ隙間**が空く。味噌の分布が地質境界と重なる話から。
回避経路は「隙間を抜ける」。壁の速度は速くしない（遅いが圧がある）。

**`gateCorn` 自販機の蓋** — `Tick(dif.iv(2.6))` / `dif.n(8)` / `dif.v(72)` px/s
→ 開いたあと `dif.n(18)` / `dif.v(40)` px/s。
全方位を塞いだあと、**必ず開く**。北棟の自販機からコーンスープが消え、
三学期に戻ってくる、という原作の筋書きに対応する。

**`honshitsuWall` 本質の枠** — `Tick(dif.iv(2.4))` / `dif.v(58)` px/s / 弾種 `crossHonshitsu`
十字が中心から外へ広がる。**四隅が必ず逃げ道**になるように矩形の辺を埋める。
最終章の締めに置いている。原作の台詞
「枠が広がると、前の枠に入ってたものがこぼれて、壊れたように見える。
でも壊れてない。広がっただけ」を構造にしたパターン。

### 追尾・方向変化系

**`chaserMie` 冷笑の追尾** — `Tick(dif.iv(1.05))` / `dif.n(3)` / `dif.v(62)` px/s
＋ `Tick(dif.iv(0.9))` / `dif.n(5)` / `dif.v(48)` px/s（`pellet`）
弾種 `chaser` は緩やかに曲がる。**振り切れる速さしか持たない**のが設計上の約束で、
`turnRateMul` で曲がり方が難易度に応じて変わる。原作の「三重の冷笑」＝
追ってくるが、隙間（「まあ」の二回目）がある。

**`turnTerrace` 台地の縁** — `Tick(dif.iv(1.25))` / `dif.n(10)` / `dif.v(104)` px/s
弾種 `terrace`。一定距離で**直角に折れる**。折れる位置は撃つたびに変わるが、
折れたあとの直線は必ず読める。安全域が広いので「読む」パターンになっている。

**`reflectArena` 反射する地形** — `Tick(dif.iv(1.7))` / `dif.n(6)` / `dif.v(122)` px/s
＋ `Tick(dif.iv(0.9))` / `dif.n(3)` / `dif.v(70)` px/s
画面端で跳ね返る `reflector` と `pellet`。**寿命が短く、溜まらない**ようにしてある
（反射弾は放置すると理不尽になるため、必ず消える）。

### 対称・収束系

**`symmetryTies` 対のネクタイ** — `Tick(dif.iv(0.62))` / `dif.n(3)` / `dif.v(84)` px/s
対称位置に必ず反対色（`riceNavy` / `riceEnji`）が現れる。
「見た目が美しい」ことを目的にしたパターン。

**`convergeSpread` 掲示板** — `Tick(dif.iv(3.0))` / `dif.n(16)` / `dif.v(92)` px/s
外周から中心へ収束し、また散る。発射間隔が長いので、1 回ごとに
「集まる → 散る」を目で追える。掲示板に書き込みが集まっては流れていく様子。

**`chainDelay` 遅れて届く投稿** — `Tick(dif.iv(2.0))` / `dif.n(9)` / `dif.v(84)` px/s
＋ `dif.n(6)` / `dif.v(74)` px/s
時間差で発射され、**最後に同期する**。同期した瞬間に隙間が閉じるので、
それまでに位置を取る必要がある。原作の「本質配信」の広がり方。

### 線・段丘系

**`contourWaves` 等高線** — `Tick(dif.iv(1.15))` / `dif.n(6)` / `dif.v(96)` px/s
弾種 `contour`。片側から壁が掃引し、**隙間は上下に動く**。
密な線と疎な線を混ぜて「傾斜」を描く。本作の中心的な比喩。

**`terraceStairs` 段丘を掘る** — `Tick(dif.iv(0.42))` / `dif.n(7)` / `dif.v(96)` px/s
左右から交互に段が入る。リズムで避けるパターン。河岸段丘＝
「時間を掘る」という塀勝也の授業そのもの。

### 特殊

**`starfield` 昼の星** — `Tick(dif.iv(0.55))` / `dif.n(5)` / `dif.v(150)` px/s
→ `dif.v(120)` px/s へ**減速して止まりかける**。速い弾は減速するので、
「速さで殺す」パターンにならない。昼でも星はある、という零の台詞から。

**`finaleDense` 密度** — `Tick(dif.iv(0.36))` / `dif.n(3)` / `dif.v(58)` px/s
＋ `Tick(dif.iv(1.6))` / `dif.n(18)` / `dif.v(44)` px/s（`orbGold` / `riceEnji` / `riceGold`）
**最も多いが最も遅い。** 残り時間の少なさを弾数の多さに写像したパターンで、
原作の「残り時間が少ないほど、密度が上がる」をそのまま実装している。
弾速 44〜58 px/s は自機の低速移動より遅い。

**`rainRice` 米の雨** — `Tick(dif.iv(0.42))` / `dif.n(9)` / `dif.v(88)` px/s
列で降る。**ランダムではない**ので、必ず列の間を歩ける。味噌・餅・米の話。

**`halfStep` 半歩** — `Tick(dif.iv(1.9))` / `dif.n(6)` / `dif.v(70)` px/s
四方から少しずつ寄る。**中央は開いている**。第十三章「伊豆見、半歩ずれる」。

## フェーズ内での組み合わせ方

各フェーズは `layers: [{ p, at, until, ivMul, denseMul }]` を持つ。
`at` はフェーズ開始からの秒数、`until` は終了秒。

例 — 第 1 章フェーズ 4「は？」（HARD、`tier: 'extra'`）:

```js
layers: [
  { p: 'chaserMie', until: 17 },                 // 追尾を 17 秒で止める
  { p: 'ringsNavy', until: 10, ivMul: 1.7 },     // 輪は 10 秒まで・間隔を 1.7 倍に薄める
  { p: 'finaleDense', at: 17 },                  // 最後の 9 秒だけ密度
]
```

**この `until` は実測から決めた。** 追尾弾と輪を最後まで重ねると、
「輪の内側」だけが逃げ道になり、そこに追尾弾が入って詰む
（回避 AI が HARD で 5 回中 3 回死んだ）。追尾を先に止めることで、
密度が上がる時間帯には追尾弾が残っていない状態を作っている。
