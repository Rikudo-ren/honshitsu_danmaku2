# 原作からの翻案

原作: 『偏差値60の教室から✝本質✝が漏れ出している件について』（4,021 行 / 二学期編に続く）

**方針: 翻案。** 世界観・象徴・台詞を尊重しつつ、弾幕サバイバルゲームとして再構成する。
場面を順に再現するのではなく、原作の**構造**をゲームのルールに写像する。
区分は「採用（原作にある）」「翻案（原作を変形した）」「独自（ゲームのための新規）」
「除外（今回は扱わない）」の 4 つ。ゲーム内の用語集（アーカイブ画面）にも同じ区分を掲載している
（`src/data/script.js` の `ADAPTATION_NOTES`）。

## 採用 — 原作にあるものをそのまま使った

- 桐葉高校の二重構造（南棟 / 内進 / 偏差値70 / 紺ネクタイ、北棟 / 理数科 / 偏差値60 / えんじネクタイ）
- ✝本質✝ という記号と、その「わからないが、ある」という定義
- 両馬二郎の三層の書き込み（✝本質✝系・三重県臣を用いた創作・塀勝也関連）
- 三重の「は？」「やめろ」の応酬
- 塀勝也の地理の授業（糸魚川-静岡構造線 / 味噌の分布 / 河岸段丘 / 上から描く断面図）
- 北棟の自販機のコーンスープの不在と帰還
- 寺地星の「星と地面とせいちちゃんねる」と本質配信（紙に書いて読み上げる形式）
- 砂糖東洋が終電の充電切れで初めて窓の外を見たこと
- 「見えないけどある」／等高線の比喩（零）
- 同じ地形図を三度見せる教育と、待つこと
- 寺地の配信の炎上・切り抜き・沈黙・非公開での再開（三十二人）
- 「笑われた数だけ、本質に近づく」
- **「残り時間が少ないほど、密度が上がる」**（三年目 一学期の締め）— これがゲームのコア
- 桜の下を、紺のネクタイもえんじのネクタイも通るという結び

## 翻案 — 原作を変形してゲームにした

| 原作 | ゲームでの扱い |
|---|---|
| 戦闘が無い | **耐久型弾幕**。攻撃手段を持たせず、時間経過＝進行とした |
| 授業・配信・学期という連続した時間 | 章＝1 時限 / 1 授業 / 1 配信 / 3 年間、フェーズ＝24〜30 秒の区切り |
| 「敵」がいない | ボスは倒す対象ではなく、**その人が体現しているもの**。HP を持たず、時間で形態が進む |
| 三重の冷笑のグラデーション | 4 フェーズに写像: 区分け → 見えない壁 → まあ → は？ |
| 塀勝也 | 第 2 章と最終章の両方に登場させ、**同じ「地図」を二度見せる**（原作の「同じ地図を三度」の圧縮） |
| 語り | フェーズ移行時に原文を短く引用表示（`quote`）。作品の語りを残すため |
| 台詞の話者 | 一部変更（例: 「お前最近、ヘイカツの授業中に前見てるよな」を砂糖→伊崎へ）。ゲームの会話の流れに合わせた |
| 校章・日程・季節などの細部 | 圧縮。短編として密度を上げるため |

## 独自 — ゲームのための新規

| 要素 | 由来と理由 |
|---|---|
| **自機＝紙飛行機** | 原作に固有の設定はない。物語が「紙」の上で起きること、原作の書き込みが紙であることからの着想 |
| **観測システム** | 櫻優の「好意は観測されていない状態で量子的に重ね合わさっている」と、零の等高線の比喩から。**攻撃しないゲームにおける唯一の干渉手段**として実装 |
| 弾幕 21 種とその名称 | すべて本作の新規。原作の語彙（区分け / 構造線 / 段丘 / 掲示板 / 密度 …）を借りて命名 |
| ボス最終形態「地形図の向こう側」 | 本文の語を造形化。顔は塀勝也、体は等高線 |
| スコア・かすり・残機・観測ゲージ | ゲーム的要素。原作には無い |
| 難易度 3 段階と数値設計 | 本作の新規 |
| 背景 4 種 | 学校 / 地質境界 / 段丘 / 等高線。原作の場所を 4 層パララックスで描いた |
| 楽曲 10 曲 | Web Audio による合成。外部音源は使っていない |

### 最終ボスについて

最終章のボスを誰にするかは原作者から一任された（「おまかせ」）。
結論は上記のとおり **塀勝也の顔を持つ「最後の地形図」** とした。理由:

1. 原作の「同じ地図を三年間出して、見る側が変わるのを待っていた」という結論が、
   本作のルール（**攻撃できない・時間が尽きるまで耐える**）と最も強く対応する。
   「待つ」ことがゲームの主題であり、待ち続けた教師が最後の相手になる。
2. 「✝本質✝」そのものを人型のラスボスにすると、原作の
   「定義できない」という性質が壊れる。だから最終形態は**人型を保たない**
   （腕を描かず、体が等高線になる）。
3. 第 2 章で一度同じ人物と戦わせることで、「同じ地図を二度見る」体験になる。

## 除外 — 今回は扱わない

- 原作後半（二年生編・三年生編）のエピソードの大部分
- 恋愛学の法則の詳細な列挙、ハワイ編、球技大会編など

範囲を絞ることで、短編として密度を上げることを優先した。
これらは「無かったこと」にはしていない——用語集にその旨を明記している。

## 立ち絵の扱い

原画は**採用**（そのまま使う）だが、**切り出しと縮小は翻案**である。

| 用途 | 加工 |
|---|---|
| 会話のカットイン `assets/cutin/` | 原画からキャラクターを切り出し、最大 320px 高に縮小、周囲を透過 |
| 名前横の顔アイコン `assets/face/` | 原画の顔部分を 48×48 に切り出し |
| 戦闘中のボス | **原画は使わない**。観察してドット絵で描き起こした（[BOSSES.md](BOSSES.md) 参照） |

切り出しは `tools/build-assets.py` が行い、元ファイル名を
`assets/asset-manifest.json` に記録している。
どの原画を使ったかを追跡できるようにするためである。
