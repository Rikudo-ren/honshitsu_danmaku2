# ✝本質✝ — ドキュメント

耐久型ドット絵弾幕ゲーム『✝本質✝』の設計・素材・検証に関する文書。
原作は小説『偏差値60の教室から✝本質✝が漏れ出している件について』。

## はじめかた

```bash
npm install          # @napi-rs/canvas のみ（開発時の検証に使う）
npm start            # http://localhost:8080 を開く
```

ブラウザで開いて「はじめる」を押すと遊べる。**音声は最初の操作で有効になる**
（ブラウザの自動再生制限のため、タイトルで任意のキーを押した時点で鳴り始める）。

| 操作 | キーボード | タッチ / マウス |
|---|---|---|
| 移動 | 矢印 / WASD | 画面をドラッグ（相対移動。指で自機が隠れないよう少し上に出る） |
| 低速移動（精密） | Shift 押しながら | ドラッグ中に 2 本目の指を置く |
| 決定 | Z / Enter / Space | タップ |
| キャンセル / 戻る | X / Backspace | — |
| **観測**（唯一の干渉手段） | X / Backspace（ゲージ満タン時） | 観測ボタン（画面右下） |
| ポーズ | Esc / P | ポーズボタン（画面左下）／ポーズ中は項目をタップで選ぶ |
| リトライ | R（ゲームオーバー時） | — |
| 全画面 | F | — |
| ミュート | M | — |

## このゲームの核

**自機は攻撃できない。** 各章のタイマーが尽きるまで弾を避けて生き延びると
STAGE CLEAR。残り秒数は常に画面右上に表示され、フェーズ進行を駆動する。

唯一の干渉手段は**観測**——弾に近づいて「かすり」を取ると観測ゲージが溜まり、
満タンで発動するとボスが硬直し、周囲の弾が消える。攻撃ではなく「観測」。

## 検証コマンド

```bash
npm test                              # アセット / 楽曲 / 全パターン
npm run test:patterns                 # 弾幕 21 種 × 3 難易度
node tools/playthrough.js --runs 2    # 回避 AI に通しでクリアさせる（12〜24 ケース）
npm run frames                        # 実フレームを 47 枚 PNG に描く
node tools/build-font.js              # 日本語ピクセルフォントを再生成
```

結果は [VERIFICATION.md](VERIFICATION.md) に記録している。
