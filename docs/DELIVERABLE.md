## 0. 遊び方 (開発者向け)

```
npm install
npm run dev          # http://localhost:5173 (Vite)
node tools/headless.mjs shot   # 17 フェーズの画面キャプチャ (playtest/)
node tools/headless.mjs sim    # 17 フェーズ × 3 難易度の自動プレイ集計
node tools/headless.mjs ui     # タイトル〜リザルトの画面キャプチャ
```

操作: 移動 = 矢印/WASD、低速 = Shift、ボム (✝本質✝) = X、ポーズ = P/Esc、全画面 = F。
（操作の割り当ては `src/core/input.js` が正。実機での確認は未了。）

## 2. キャラクターの表現方針

方針の 4 分類: (1) 立ち絵をそのまま使う / (2) 立ち絵をゲーム用スプライトに翻案 / (3) 立ち絵の要素を外部素材に統合 / (4) 立ち絵に着想した独自表現。

| キャラ | 採用方針 | 具体 |
|---|---|---|
| 両馬 二郎 (ryoma) | (2) | 立ち絵を `tools/make_portraits.py` で減色 (28/40/56 色)・輪郭線化し、会話用 (px / px_hi) とボス用 (boss, 176px) を生成 |
| 寺地 星 (terachi) | (2) | 同上 |
| 倉石 暁 (kuraishi) | (2) | 同上 |
| 數理 零 (rei) | (2) | 同上 |
| 自機「観測者」 | (4) | 立ち絵に着想した制服 (紺・えんじ) の独自ドット絵。立ち絵の顔を使わない |

- 立ち絵は全て `source_assets/portraits/` に無改変で保持 (ローカルのみ、Git 対象外)。
- **立ち絵をそのまま貼るのは会話カットインの一部のみ** (減色済み)。ボスは立ち絵の切り抜きを縮小・減色したもの。
- 不明: 各キャラの立ち絵の差分 (表情) を、どの場面で使うかの仕様は網羅していない。
- 注: 現在の画面では、ボス画像が暗色・グレースケールで描かれる最終形態があるが、これが意図した演出か、描画の副作用かは未確認。

| 安全帯の幅 | 1.34 | 1.00 | 0.78 |

| 残機 | 4 | 3 | 2 |
| 被弾後の無敵 (秒) | 2.6 | 1.9 | 1.45 |
| フェーズ時間倍率 | 1.10 | 1.00 | 0.94 |
| ボム (✝本質✝) 数 | 3 | 3 | 2 |
| グレイズ獲得倍率 | 1.35 | 1.00 | 0.85 |
| 弾の寿命倍率 | 0.85 | 1.00 | 1.12 |

**依頼された項目との差 (未達):**
- 「フェーズ数の差」は未実装。3 難易度とも同じ 17 フェーズ。
- 「同時発射数」「発射間隔」は個別に分けていない。弾数倍率 (density) で代用している。
- 「難易度ごとにクリア可能か」は、自動プレイ (先読みボット) では 3 難易度すべてでフェーズ全滅 0 回。
  ただし、ボットは反応遅延がなく、残機もフェーズごとにリセットして検証しているため、人間のクリア可能性とは別物。

## 6. ボスの形態・弾幕テーマの構造

- 各幕のボスは `forms` (形態) を持ち、フェーズごとに形態番号が決まる (表 4 参照)。形態ごとに色味・動きが変わる設計 (`src/game/boss.js`)。
- ボスの状態: idle / float / 攻撃予兆 (windup) / 攻撃 / 被弾反応 / 形態移行 / 撃破 (dissolve)。コード上の状態機械として実装。
  実機での見た目と各状態の動きの確認は未了。
- 各フェーズは `design` 欄に、発射位置 / 弾速 / 予告 / 回避ルート / 役割 / 原作対応を記述 (`src/game/stages.js`)。
  全フェーズが設計欄を持つかどうかの網羅確認は未了 (推測です)。
- 弾幕のパターン語彙 (円形拡散・螺旋・回転レーザー・壁とすき間・開閉壁・追尾・方向転換・画面端反射・対称・時間差連鎖・安全中心・終盤の高密度) は `src/game/patterns_lib.js` と `patterns.js` に実装。
  各パターンの個別の実プレイ検証は、先読みボットによる全フェーズ集計にとどまる。
