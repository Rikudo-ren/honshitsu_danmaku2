# 画作り

解像度は **640×480**（ゲーム内のプレイフィールド。背景の一部は画面外まで描く）。
すべての弾・自機・ボス・背景・エフェクトは**この解像度のピクセル格子で描いている**。
画像を貼っているのは立ち絵（カットイン / 顔アイコン）だけで、
それ以外は 1 枚の PNG も使っていない。

## 3 つの原則

1. **弾が最も明るい。** 弾には必ず白いコアを置く。背景・ボス・エフェクトは弾より暗い。
2. **背景は弾を隠さない。** 全層で彩度を落とし、明度を 40% 以下に制限する。
   弾と同系色の面を大きく置かない。
3. **ボスは背景に溶けない。** シルエットの後ろに暗い下地を敷き、輪郭で存在感を出す
   （後光の alpha は 0.14〜0.28 に抑えて弾を白飛びさせない）。

## 描画順（厳密に固定）

```
① 背景（4 層パララックス）
② レーザーの予告線
③ 弾のグロー（加算合成）
④ 弾のコア
⑤ レーザー本体
⑥ 画面外スポーンの予告マーカー（WarnMarker）
⑦ ボス
⑧ 自機（無敵中は点滅）
⑨ エフェクト（かすり・被弾・フェーズ移行）
⑩ HUD
```

弾のグローを加算で重ね、その上にコアを不透明で置く。
これにより**弾が重なってもコアだけは必ず読める**。

## 読める弾の作り方（`src/art/bullets.js` / 22 種）

- すべての弾は「中央 (0,0) を基準に w×h の箱へ描く」関数として定義する。
- コアは白 `#fffbe8`。周囲に弾種ごとの色を 1〜2 段置く。輪郭に暗色を 1px。
- 弾種は原作の語彙から: `riceNavy` / `riceEnji` / `riceCream` / `riceGold` /
  `riceMiso` / `riceCyan` / `chaser` / `terrace` / `reflector` / `contour` /
  `star` / `pellet` / `crossHonshitsu` / `orbGold` ほか。
- 回転する弾は回転スプライト（`src/art/sprites.js`）を 32 分割で事前ベイクしている。
  **呼び出し側が `ctx.rotate(b.rot)` してから `drawImage` する**（ベイク側では回さない）。

## ボスの形

- 頭部 `drawHeadMap(headKey, ...)` — 顔の形・髪・眼鏡・口を px 単位で描く。
  表情は `idle` / `grim` / `closed` / `wide` の 4 種。
- 体 `drawBodySuit` / `drawBodyCardigan` / `drawContourBody`。
- 線の太さは `px`（通常 3）を単位にする。**px の整数倍以外の線幅を使わない**。

`drawContourBody`（最終形態）だけは例外で、線の間隔そのものが意味を持つ:
3px（form 0〜2）/ 2px（form 3）ごとに横線を引き、7 本ごとに「主曲線」として太くする。
これは地形図の主曲線と補助曲線の区別であり、
**線が密なところ＝傾斜が急**という原作の一行をそのまま描いている。

## 配色

`src/art/palette.js` にすべて集約。

- `RAMP` — 17 種の 4 段ランプ（暗 → 明）。弾・エフェクト・UI はここから取る。
  原作固有の色として `tieNavy` / `tieEnji`（ネクタイ）、`corn`（コーンスープ）、
  `miso`（味噌）、`honshitsu`（✝本質✝の光）を定義している。
- `STAGE_THEME` — 章ごとの主色・副色・アクセント・オーラ・背景種別。
- `PHASE_ACCENT` — **フェーズごとの配色**（[BOSSES.md](BOSSES.md) の表を参照）。
- `UI_PALETTE` — UI 色。背景 `#05060c`、文字 `#e8ecf7`、補助 `#8b94ad`、
  アクセント `#f0cf6a`、警告 `#e05575`、成功 `#7fd6a0`。
- `luminance()` / `contrastRatio()` を用意し、背景と弾の明度差を検証できるようにしている。

## 背景（`src/art/backgrounds.js`）

4 層のパララックス。奥から「空/壁 → 構造 → 記号 → 手前の粒子」。
章ごとに別の図形を描く:

| 章 | 種別 | 内容 |
|---|---|---|
| 1 | `geometric` | 校舎の窓・階段・廊下の幾何学 |
| 2 | `boundary` | 地質境界（左右で色が変わる地形の帯） |
| 3 | `contour` | 等高線が流れる |
| 4 | `contour` | 同じ等高線だが密度が高く、金色 |

`flashScreen` / `pulseOnce` / `shakeScreen` を備え、フェーズ移行や被弾に使う。
**揺れ・発光は弾の視認性を損なわない範囲に制限している**（alpha と持続時間に上限）。

## 立ち絵の扱い（重要）

原画は**そのままの形では画面に貼っていない**。用途ごとに次のように扱っている。

| 用途 | 扱い | 加工 |
|---|---|---|
| 会話カットイン | 採用（原画を使用） | バストアップを切り出し、最大 320px 高に縮小、彩度・コントラストを微調整 |
| 顔アイコン | 翻案（原画を再構成） | 顔を 48×48 に切り出し、ゲームのパレットへ減色、輪郭線を付けてドット絵として読ませる |
| 戦闘中のボス | **独自**（原画を使わない） | 観察してピクセルで描き起こす |

生成は `tools/build-assets.py`。使用した原画のファイル名は
`assets/asset-manifest.json` に記録している。

### 原画から何を観察して取ったか

`src/art/bosses.js` の頭部は、原画から次の点を観察して描き起こした。

| 人物 | 観察した点 | ドット絵での扱い |
|---|---|---|
| 三重 県臣 | 眼鏡、目つき、口角、紺のネクタイ、組んだ腕 | 眼鏡の反射を常時動かす（`glassGlint`）。腕は組んだまま肘だけ動かす |
| 塀 勝也 | カーディガン、穏やかな目、大きな地形図 | 手前に地形図（`drawMapProp`）を掲げる。線がゆっくり回る |
| 倉石 暁 | 逆立つ髪、✝のノート、後光 | 髪を上に張り出させ、頭上の ✝ を大きく光らせる |
| 地形図の向こう側 | 塀勝也の顔 ＋ 等高線 | 顔は塀勝也のまま、体を等高線にする。**腕を描かない** |

シルエット・比率・髪・目・表情・服装・小物・配色・線の質感を参照したが、
640×480 で読めることを優先して**簡略化した部分がある**（詳細は [ADAPTATION.md](ADAPTATION.md)）。

## 文字

- 本文（日本語）: **Fusion Pixel 12px**（1px 格子でデザインされた本物のピクセルフォント）。
  12px の整数倍（12 / 24 / 36）で描く。
- 数字・UI: **Silkscreen**（400 / 700）。
- ✝ はフォントに存在しないため、`src/art/glyph.js` が**ビットマップから自前で描く**
  （`drawCross` / `CROSS_BITMAP`）。文字列中の ✝ は `drawText` が手動レイアウトで混ぜる。

以前は DotGothic16（アウトラインフォント）を使っていたが、
輪郭が滑らかすぎてドット絵と質感が揃わなかったため Fusion Pixel 12px に変更した。
