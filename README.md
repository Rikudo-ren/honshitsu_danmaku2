# ✝本質✝ — 耐久型ドット絵弾幕ゲーム

**原作小説**『偏差値60の教室から✝本質✝が漏れ出している件について』を
**弾幕サバイバルゲームとして翻案**したものです。

> **自機は攻撃できません。** 各章のタイマーが尽きるまで弾を避けて生き延びると STAGE CLEAR。
> 残り秒数は常に画面右上にあり、フェーズ進行を駆動します。
> 唯一の干渉手段は**観測**——弾に近づいてかすりを取り、ゲージが満タンになったら発動すると、
> ボスが硬直し周囲の弾が消えます。撃つかわりに、よく見る。

## 遊ぶ

```bash
npm install
npm start          # → http://localhost:8080/
```

ブラウザで開いて「はじめる」を押してください。
ビルドは不要です（素の HTML + JavaScript）。

| 操作 | キーボード | タッチ / マウス |
|---|---|---|
| 移動 | 矢印 / WASD | 画面をドラッグ（相対移動） |
| 低速移動（精密） | Shift を押しながら | ドラッグ中に 2 本目の指を置く |
| 決定 | Z / Enter / Space | タップ |
| 観測（唯一の干渉手段） | X / Backspace（ゲージ満タン時） | 画面右下の「観測」ボタン |
| ポーズ / 戻る | Esc / P | 画面左下のポーズボタン |
| リトライ | R | — |
| 全画面 | F | — |
| ミュート | M | — |

画面内の「観測」「ポーズ」ボタンは、タッチが使われた端末（またはタッチ専用端末と
判定した端末）でだけ出ます。マウス＋キーボードなら HUD は数字とゲージだけです。

## 収録内容

| | |
|---|---|
| 章 | 4 章（南棟と北棟 / 火曜三限、味噌の地政学 / ✝本質✝が漏れ出す / 最後の地形図） |
| フェーズ | 各章 3〜4 フェーズ、1 フェーズ 24〜30 秒 |
| ボス | 4 体。フェーズごとに色と形態が変わる。HP は無く、時間で進む |
| 弾幕 | 21 種 |
| 難易度 | EASY / NORMAL / HARD（同時弾数・間隔・弾速・軌道変化・安全域・残機・無敵時間が変化） |
| その他 | 練習モード、用語集、記録、設定（音量・走査線）、自動保存 |

## 設計方針

- **難易度は弾速では稼がない。** 弾速には上限（EASY 301 / NORMAL 341 / HARD 373 px/s）があり、
  差は同時数・発射間隔・軌道変化・安全域・ボスの動きで作っています。
- **反応できない弾を出さない。** 画面外からの弾は必ず予告マーカーを経由し、
  レーザーは必ず予告線が出てから発射されます。
- **ボスは自分から近づきすぎない。** 自機が画面下半分に居るとき、
  ボスは中心間距離 140px を下回りません（弾が出現即直撃になるのを構造的に防ぐため）。
- **瞬間死させない。** 残機・無敵時間・その場復帰があります。

## 検証

```bash
npm test              # アセット / 楽曲 / 弾幕 21 種 / 公平性の不変条件
npm run test:full     # 上記 + 通しクリア検証 + フレーム描画 + 音声の波形検査
```

検証は Node + `@napi-rs/canvas` 上で**ゲーム本体のコードをそのまま読み込んで**実行します。
回避 AI はゲームの入力系を通して操作するため、検証用の別実装はありません。

直近の結果は [docs/VERIFICATION.md](docs/VERIFICATION.md) を参照してください。

## 素材について

画像・音声はすべて本作が生成・合成したもので、外部の素材は使用していません。
外部から取得したのは**フォント 2 種**（Fusion Pixel 12px / Silkscreen、いずれも SIL OFL 1.1）だけです。
立ち絵と原作テキストは原作プロジェクトの提供物です。
詳細とライセンス全文は [docs/ASSETS.md](docs/ASSETS.md) / [docs/CREDITS.md](docs/CREDITS.md) にあります。

```
  art/            弾・自機・ボス・背景・立ち絵・エフェクト・字形
  game/           難易度・弾幕パターン・フェーズ・自機・弾管理・状態機械
  ui/             HUD・各画面
  data/           台詞・用語集・クレジット・翻案区分・原作抜粋
assets/           ゲーム用に加工した画像とフォント
tools/            検証・生成ツール
docs/             設計・素材・検証の文書
```
